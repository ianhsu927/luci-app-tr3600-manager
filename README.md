# TR3600 硬件管家 0.2.2

LuCI：状态 → TR3600 硬件管家。默认每 10 秒刷新，可关闭或设置 3–300 秒；浏览器本地保存刷新设置。

## 硬件状态

型号、固件、CPU 温度、风扇 PWM/冷却档位、物理网口、启动槽位、MTD、UBI 卷和文件系统空间。没有 RPM 反馈时不显示实际转速。槽位不代表备用镜像有效。

## 灯光开关

在管家主页面关闭指示灯或恢复系统灯效，不增加独立菜单。使用固件原生 LED 服务及 `system.@system[-1].leds_off`，设置在重启进入 OpenWrt 后自动应用。

灯名动态读取，已只读确认本机为 `red:status`、`white:status`。未提供控制接口的网口灯及 OpenWrt 启动前的灯光不受控制。其他程序重载灯效时可能暂时重新点亮。

系统设置有待提交的修改时拒绝切换，避免一起提交其他设置。灯光操作失败时尝试回滚对应配置及运行状态。缺少原生接口时禁用按钮。

灯光功能已于 2026-10-03 更新到 Cudy TR3600 v1 / OpenWrt 25.12-SNAPSHOT。真实 RPC 验证关灯后两灯亮度为 0、恢复后白灯亮度为 1、非法参数拒绝、LED 服务重新应用保存的关灯设置。未重启路由器；网页验收因内置浏览器访问检查不可用而未完成。

灯光和风扇功能共用管家页面及 ACL。风扇功能需完整安装 RPC、辅助脚本、UCI 配置和保护服务，缺少后端会出现 `tr3600.fan/status: Object not found`。源码构建包含上述文件；手动部署后需重启 rpcd，并启用、启动 `tr3600-fan` 服务。

## 风扇设置

- 系统默认：恢复本次启动中首次调整前的四个风扇温控阈值。
- 自定义曲线：设置 1–4 档升档温度，40–85°C，相邻至少相差 5°C。
- 手动最低档位：1–4 档，高温允许继续升档。其余档位使用输入的曲线阈值。
- 档位 PWM：0/64/128/192/255；手动不提供停转档位。
- 内核提供固定 5°C 降档滞回，当前不支持修改。
- 内核 step_wise 温控和 hot/critical 触发点保持启用；只调整验证过的四个风扇 active 触发点。
- 自定义/手动模式每两秒检查 CPU 温度，高于等于 85°C 或读数异常时尝试设置 4 档。内核曲线也限制 4 档阈值不超过 85°C。

控制仅支持已核对的 Cudy TR3600 v1 驱动布局：风扇类型、档位表、温控策略、绑定和滞回必须匹配，否则拒绝写入。未禁用内核温控；手动模式不是锁定转速。其他软件修改同一温控接口可能影响结果。

设置保存到 /etc/config/tr3600_fan，procd 服务在启动时应用。默认配置是 system。配置失败时尝试恢复操作前的阈值和配置。应用自定义模式前必须有保护服务运行。

系统默认模式不附加 85°C 保护，由固件原有温控管理。保护服务不是硬件故障保险：未提供风扇转速反馈，不能检测机械停转。传感器、驱动或服务异常可能使设置无法生效。

## 构建

放到匹配固件源码的 package/luci-app-tr3600-manager，启用对应包后执行：

```sh
make package/luci-app-tr3600-manager/compile V=s
```

依赖 luci-base、rpcd、libubox、jshn、ubus、flock。使用固件对应的 apk/opkg 安装。源码 ZIP 不是安装包。
